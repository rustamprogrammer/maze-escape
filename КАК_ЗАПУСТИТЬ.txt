Проект Maze Escape

1. Открой папку maze-escape в IntelliJ IDEA и выбери Project SDK 17 или новее.
На этом компьютере уже установлен JDK 25:
C:\Users\ADMIN\.jdks\openjdk-25.0.1
Обычная команда java сейчас указывает на старую Java 8. Поэтому в терминале
используй полный путь к новой Java или настрой JAVA_HOME и PATH.

2. Пока в data/ лежит учебный пример tiny, поскольку Student ID не получен.
Не сдавай его как свой персональный вариант. Чтобы создать свой вариант,
из корня проекта выполни в PowerShell, заменив ID, имя и группу:

& "$env:USERPROFILE\.jdks\openjdk-25.0.1\bin\java.exe" tools/Personalize.java "ТВОЙ_ID" "Имя Фамилия" "Группа"

ID передаётся строкой: начальные нули важны. Скрипт сам скомпилирует проект,
создаст персональные входные файлы, запустит Main и обновит README, PNG и HTML.

3. Проверка:
& "$env:USERPROFILE\.jdks\openjdk-25.0.1\bin\java.exe" tools/Check.java

После Check запусти Main, чтобы вернуть картинку своего лабиринта:
& "$env:USERPROFILE\.jdks\openjdk-25.0.1\bin\java.exe" -cp out Main

4. Открой output/maze.html двойным щелчком. В output/maze.png находится
картинка для отчёта. README.md содержит ответы, сложности, реальные замеры
и описание использования ИИ. Прочитай код, проверь и переработай ответы
своими словами перед сдачей; сведения об использовании ИИ должны быть точными.

5. В архив включена скрытая папка .git с отдельными коммитами по миссиям.
Не удаляй её при распаковке. После персонализации сохрани изменения коммитом.
Публикация на GitHub и отправка ссылки в Moodle ещё не выполнены.
